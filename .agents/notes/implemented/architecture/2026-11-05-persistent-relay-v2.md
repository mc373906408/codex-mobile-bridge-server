# Agent Note: 持久中继会话与服务端授权

Status: implemented

## Problem

每个业务读取重新建立 WebSocket、Noise 和授权，目录轮询失败又取消业务连接；共享队列满或瞬时流量超限会关闭桌面连接。客户端资格轮询和不可恢复的令牌轮换进一步放大短暂网络故障。用户确认三端同步升级、保留账号与配对、取消客户端资格自动刷新，并同时修复续期恢复。

## Decision

可选直连、服务端主动授权信令及云离线延迟撤销见 [EasyTier P2P](2026-11-06-easytier-p2p.md)；本篇的中继资格复查与关闭仍有效。

三端使用 `bridge-relay-v2`、外层版本 2 和 `bridge/control/v2` prologue。每个 binding/凭据代次复用一个 Noise 会话；服务器仍只处理密文路由。预览与安全码保持 v1。内层控制消息使用非零、单调增长的 `stream_id`；正文是 `0x01 || uint64_be(stream_id) || bytes`，控制仍为 `0x00 || JSON`。握手控制不带流 ID，运行期 ping/pong 使用流 0。请求、credit、response_start、request_end、response_end、response_ack、cancel 和 stream_error 均在对应流内；结束和取消不关闭连接。未知或退役流记录丢弃，不复用流 ID。认证失败关闭整个加密会话，业务错误仅结束一个流。

每会话最多 8 个流、每方向 4 块正文窗口，每块明文最多 32768 字节；传输大于 1 MiB 或文件端点视作大文件，每会话最多 1 个、每桌面最多 2 个。发送器在加密前公平调度，各 Noise 会话密文严格保序。服务器按绑定调度，限额用于节流；过载隔离到绑定，不能丢密文后继续使用同一 Noise 会话。

客户端取消定时资格查询，仅显式查询时更新显示。服务器建连检查、30 秒资格复查、精确到期定时和显式撤销独立执行。目录瞬时失败不撤销已验证身份或中断业务。空闲 20 秒端到端心跳，10 秒未应答断线；连接建立由单一管理器串行化，重试 1–15 秒带抖动，业务写入不重放。

刷新接口接受 `request_id`，旧令牌与该 ID 唯一标识一次轮换；加密结果保存 5 分钟，相同请求恢复原结果且不延长有效期，不同 ID 重用令牌仍撤销会话。客户端先持久化待恢复请求，持久化新凭据后再清除。

## 记录归属

[服务端审查](2026-11-03-server-architecture-and-scope-audit.md)和[关闭隔离](../bug-fix/2026-11-04-relay-channel-close-isolation.md)部分重叠，保留历史失败证据。本篇取代按请求建通道与超限即断共享连接的决定。桌面 response-peer-close、手机 response-completion 及既有 proposed 聊天恢复记录部分重叠，分别保留原始证据和界面范围；各仓库通过同名记录说明新的跨端契约。没有需要归档的完全重复记录。

## Alternatives considered

- 扩大旧队列或增加读取重试改动较小，但保留重复握手及请求关闭竞态，无法限制共享故障范围。
- 每绑定仅串行复用一个 HTTP 请求实现简单，但 SSE 会阻塞其他读取，因此使用有界逻辑流。
- 同时维护 v1/v2 便于滚动升级，但用户选择三端同步升级；保留数据格式而明确拒绝旧传输协议。
- 客户端资格检查容易做界面反馈，但客户端可修改；官方云资格完全由服务端执行。

## Testing

真实 Go/Python/Rust/Dart 业务阶段连续 1800 秒完成 107648 次读取，只有一次业务握手（另一次是首次待批准证明），连接数为 1。SSE、通知/列表与 20 MiB 下载并发、35 秒空闲心跳、网关断线自动恢复、连续 20 次监听取消、20 MiB 上传、未知写入不重放和前后台恢复由后续独立 fault4 全链路通过。

长测首次被后台任务终止，只保留 19 分钟证据；独立进程重跑完成业务阶段，但结尾合成账号因没有目录请求导致 access token 过期，远端退出返回 401，本地退出成功。原始失败保留；夹具增加目录续期再退出后，短期完整链路通过，不将失败脚本记成整体绿色。混合测试另外发现并修复 `/api/mobile/events?after=0` 错判 SSE 路径、aiohttp 上限使用 >= 导致满大小上传帧断开、FFI 状态监听缺取消三处问题。

PostgreSQL 完整 Go 118 项通过，无跳过；部署主机隔离库重复续期与在线到期/关闭测试及候选二进制启动通过。Rust 66 项及静态检查、Flutter 完整与实际 FFI、桌面 Python/Node 按各仓库结果验收。原始日志位于 `D:/github/.codex-tools/relay-v2-20261105/`。生产切换、APK 安装及 iOS 状态在交付记录中单独核验。

## Consequences

业务读取复用已授权连接，局部取消和过载只影响逻辑流或绑定，客户端资格查询不再成为在线依赖。代价是会话、流与 UI 监听需要分别管理取消；TCP 底层中断仍使该连接全部流失败。单进程 Hub、每会话 8 流和限流默认值仍是明确上限。服务器保存短期加密续期回执；同请求恢复窗口只有 5 分钟。三端必须协调升级，iOS 真机和签名能力不能由 Windows 回归替代。
