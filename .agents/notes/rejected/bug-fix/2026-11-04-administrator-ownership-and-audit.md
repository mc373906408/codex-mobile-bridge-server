# Agent Note: 管理员认领、跨账号管理和授权审计闭环

Status: rejected — 用户明确要求保留 admin/admin 作为部署后首次登录入口，随机初始化口令不符合该要求；管理与审计继续按新提案实施。

## Problem

[服务端省察](../../implemented/architecture/2026-11-03-server-architecture-and-scope-audit.md)仍有 F3–F5：公开默认密码可以被首位访问者认领，管理台只能查看管理员自己的设备/会话，200 条截断列表无法翻页，关键授权操作缺少完整审计。用户要求这些服务端问题一并处理。

## Proposal

初始化为每个安装生成独立随机管理员密码，禁止短密码特例和缺配置时的 admin/admin 回退。首次登录继续只取得短期 setup 权限并强制更换密码。已有管理员不受启动参数覆盖；本机 reset-admin 必须使用明确提供的新强密码，保留账号身份，不输出秘密，不提供网络重置入口。

新增管理员按用户读取与撤销设备、绑定和会话的独立接口，写入时复核管理员会话和目标归属，事务提交后关闭对应在线通道。普通账号接口保持本人作用域。用户搜索由服务器执行，用户、设备、绑定、会话、兑换码、兑换记录和审计使用稳定游标分页，前端在切换用户/搜索时丢弃迟到响应。

审计保存操作者、受影响账号、设备/会话、目标及安全的前后状态，覆盖登记、绑定开关与撤销、会话撤销/退出、通知同意、账号禁用及管理员操作；审计与变更同事务，失败不留下无记录的授权变更。没有状态变化的轮询和重复注册不持续新增审计；不保存密码、token、公私钥、邮件正文或聊天内容。清理失败给出不含数据库私密数据的结构化错误。

继续使用当前未上线数据库基线，不提供旧开发数据升级。源码、测试和本地合成验收不操作部署数据库或真实用户。

## 记录归属

本仓活跃记录已按 administrator、audit、session、device 检索：全局省察部分重叠，保留旧复现和限制并更新处置状态；[当前 schema](../../implemented/simplification/2026-11-04-prerelease-account-and-binding-schema.md)继续持有无需历史兼容的决定；[推送撤回](../../implemented/bug-fix/2026-11-04-push-withdrawal-independent-of-desktop-access.md)继续持有缩减权限独立于桌面资格的规则。没有同主题 proposed/rejected 待合并记录。

## Alternatives considered

- 保留默认密码并要求立即修改，对部署者更省操作，但不能证明首个访问者是部署者；选择随机安装秘密和受限 setup。
- 放宽普通设备接口允许管理员跨账号可复用旧路由，却模糊客户端权限边界；选择显式目标账号的管理员接口。
- 只增加列表上限改动较少，但仍会截断且无法搜索未加载用户；选择服务器搜索及稳定游标。
- 提交变更后异步写日志可减少事务耦合，但日志失败时无法重建授权变化；选择审计失败回滚该变更。

## Acceptance criteria

新安装无弱默认密码；未知初始化配置拒绝创建管理员，现有管理员不被启动/重置默认值接管。跨账号管理只有有效管理员可用，目标错配与 CSRF 拒绝，撤销即时关闭目标通道并取消对应推送。超过单页的搜索/翻页无遗漏重复，切换账号后的旧响应不能覆盖当前面板。审计记录包含前后状态、无秘密，失败可回滚业务操作。完整 Go/PostgreSQL、Node/Python、笔记门禁与相关页面回归通过。

## Risks

操作者需保管随机初始化秘密；重置必须明确供应新密码。审计增加事务写入和保留空间，游标只保证按排序遍历，不是跨请求数据库快照。单进程中继容量、真实部署恢复/压测、签名客户端和厂商推送仍需各自验收，不以本次回归代替。
